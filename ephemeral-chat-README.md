Ephemeral Supabase Chatbox

This is a minimal static demo that implements 1:1 random ephemeral chatrooms using Supabase as the backend and GitHub Pages for hosting.

Contents:
- ephemeral-chat-index.html — single-page app
- ephemeral-chat-main.js — client logic using supabase-js
- ephemeral-chat-style.css — small styles
- ephemeral-chat-schema.sql — SQL to create tables, RPC, and triggers
- ephemeral-chat-deploy.md — deployment + Supabase setup steps

Next steps: configure Supabase project, run SQL to create schema, set SUPABASE_URL and SUPABASE_ANON_KEY in index.html, push to a GitHub repo and enable Pages.
